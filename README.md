# DevOS

DevOS is a browser-based desktop environment built with HTML, CSS, and JavaScript.

## Features

- Desktop-style user interface
- Interactive application windows
- Draggable windows
- Window controls
- Taskbar interface
- Multiple applications
- Responsive design
- Mouse and touch interactions

## Windows

- terminal : a small terminal tht can understand specific commands
- Clock : shows real time (local) and a stopwatch 
- about : the creator credits
- calculator : simple calculator to do arithmetic operations
- notes : to save your short notes in localStorage
- settings : To change theme color
- weather : to show the temperature and humiity in your location.
- guide : A user guide

### If you click on apps on the top bar then a dropdown of the apps will appear you can launch apps from there too.

## Technologies Used

- HTML for the structure of the interface
- CSS for styling, layouts, and responsiveness
- JavaScript for interactions and window management

## How It Works

DevOS uses JavaScript to control the interactive parts of the interface. Applications can be opened as windows, and users can move them around the desktop.
